# FreeCAD assembly

1. Install FreeCAD.
2. Import all STL from `../stl/` (after `hardware/scripts/export_stl.sh`).
3. Save assembly as `SGH1_Assembly.FCStd`.
4. TechDraw → export PDF drawings to `exports/drawings/`.

OpenSCAD sources remain parametric master; FreeCAD is for constraints and shop drawings.
