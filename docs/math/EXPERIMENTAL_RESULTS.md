
## Key findings (SGH-1, T = 298.15 K)

| Experiment | Finding |
|------------|---------|
| E1 ΔP/Δπ sweep | Maximum P = 1.66 W at ratio 0.5 (Kim–Baker) |
| E2 L_p sweep | 10 W requires L_p ≈ 6.0×10⁻¹² m/(Pa·s) |
| E3 Salinity | Brine pair Δπ = 6.92 MPa vs estuary 2.88 MPa |
| E4 CP | At J_w = 1×10⁻⁵ m/s, ~22% driving-force loss |
| E5 Ultrasonic | Net gain positive only for g ≳ 1.5 at default parasitic |
| E6 Acoustic | 96 dB → ~2.5 mW on 0.5 m² |
| E7 Column MC | pv_hydro ~98.7% of median layer sum; blue_energy ~1.1% |
| E8–E13 | RED c_river, temperature, η_mem, slip b, net energy, TSC |
