# SGH-1 Device Specification (CHORUS-Skid PRO Core)

## 1. Purpose

Extract net energy from a **salinity gradient** between high-salinity draw (desal brine simulant) and low-salinity feed (treated wastewater / river water class), mounted on a **CHORUS** frame with ports for thermal/moist (CHOR) and acoustic (AEH) subsystems.

## 2. Functional requirements

| ID | Requirement |
|----|-------------|
| FR-1 | Steady operation at ΔP ≈ 0.4–0.6 × Δπ |
| FR-2 | Feed side ≤ 10 bar gauge; draw side rated per `delta_P_star_bar` in sizing export |
| FR-3 | Continuous logging: P, Q, conductivity ×2, temperature ×2 |
| FR-4 | Leak containment: skid drip tray, brine-resistant materials |
| FR-5 | Modular membrane cartridge removable without draining both tanks |

## 3. Performance targets (50 W design point)

Generated by `python simulation/run_sizing.py --power 50`. Values in `exports/sgh1_sizing.json`.

## 4. P&ID (logical)

```
[Low-sal tank] → [Feed pump] → [Prefilter] → [Feed manifold]
      → [Membrane stack: feed | membrane | draw] → [Draw manifold]
      → [PX / throttle] → [Turbine or motor load] → [Brine return tank]
```

AEH: urban/traffic-facing panel → rectifier → DAQ power bus (supplemental).  
US transducer: feed manifold (CP enhancement, optional).

## 5. Safety

- Rupture disk on draw: 1.2 × ΔP*
- Eye wash for brine splash
- No pressure test with glass components
- Electrical GFCI on pump/DAQ

## 6. Interfaces

| Port | Size | Notes |
|------|------|-------|
| Feed inlet | 1/2 FNPT | Low salinity |
| Draw brine out | 3/4 FNPT | To return tank |
| Draw high-pressure | 1 FNPT | To PX/turbine |
| Sensor | 1/4 NPT | Pressure, temp |
| Conductivity | 3/4" compression | Feed + draw |
